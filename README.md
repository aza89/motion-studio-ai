# Motion Studio AI

A lightweight motion-design playground built with vanilla HTML, CSS, and JavaScript.

## Features

- Live motion canvas with a glowing geometric object
- Float, spin, and pulse animation modes
- Interactive rotation, scale, and speed controls
- Responsive layout and reduced-motion support
- No build step or dependencies required

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/(root)`, then Save.

The project is a starter playground intended for experimentation and extension.

## Project structure

- `index.html` — page structure
- `styles.css` — visual design and animations
- `script.js` — live controls and interaction
